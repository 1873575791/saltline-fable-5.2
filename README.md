# 盐线 · Saltline 中文版

一款单文件浏览器第一人称射击游戏。黎明时分，港区防御系统失控。你需要在机械飞鸥与机械猎犬的追击下解除封锁，并在第二章返港，彻底终止“港务长”的离线副本。

**[在线试玩](https://1873575791.github.io/saltline-fable-5.2/)**

## 两章战役

### 第一章：断链行动

切断堆场、仓库和码头的三处通信中继，然后登船撤离。通关后，行动简报会揭示残留的“回声”信号，并提供第二章入口。

### 第二章：回声协议

1. **回收黑匣子**：从码头返港，前往仓库，靠近橙色黑匣子并按住交互键 3 秒。
2. **守点上传**：到堆场中继按住交互键建立连接，在绿色圆环的 8.5 米范围内守住 45 秒。可以自由移动和射击；离开范围会暂停上传，返回后继续。上传过程中有两轮增援。
3. **关闭离线核心**：前往码头橙色控制柜，按住交互键 3.5 秒注入停机密钥。敌方机械停止行动后，返回撤离船，完成战役。

仓库和堆场各有一个绿色补给箱，靠近后自动领取：最多恢复 45 点生命、补充 90 发备弹，备弹上限 240 发。生命和备弹均充足时不会消耗补给。

每完成一个阶段会建立**本局检查点**。死亡后点击“从检查点重试”，保留已完成阶段；正在上传的阶段需重新接入并上传。“重新开始本章”会清除本局检查点。

章节解锁与第二章通关标记保存在本机浏览器的 `saltline.campaign.v1` 中，刷新页面后可从主菜单再次进入已解锁的第二章。检查点仅在当前这一局有效，不提供跨设备存档；浏览器禁止本地存储时仍可连续游玩两章。

第二章沿用现有港区地图与两类敌人，新增了黑匣子、离线核心、守点范围和补给箱。

## 汉化内容

- 主菜单、暂停菜单、死亡提示、行动简报与评级。
- 画质、音量、视角、全屏等设置及键鼠、触屏、手柄操作说明。
- 任务目标、交互提示、弹药提示、击杀反馈、指南针与无线电字幕。
- 加载提示、无障碍标签和中文字体、行高适配。

保留游戏原名 Saltline、武器型号、按键名称和场景中的工业标识。第一章沿用原版任务；第二章是本仓库新增的后续剧情和玩法。

## 本地运行

无需安装依赖，在项目目录运行：

```sh
python3 -m http.server 8731
```

然后打开 <http://localhost:8731>，点击“开始行动”。浏览器会请求锁定鼠标，按 `Esc` 可以释放并暂停。

## 操作

| 动作 | 按键 |
| --- | --- |
| 移动 | W / A / S / D |
| 转动视角 | 鼠标 |
| 开火 / 瞄准 | 鼠标左键 / 右键 |
| 换弹 | R |
| 任务交互 | 靠近目标后按住 E（手机按住“交互”，手柄按住 Y） |
| 跳跃 / 冲刺 | Space / Shift |
| 蹲伏 | C 或 Ctrl |
| 近战 | F |
| 暂停 | Esc 或 P |

手机使用屏幕左侧移动、右侧转向，以及屏幕上的操作按钮。手柄操作见游戏内“操作说明”。

## 来源与署名

本仓库是《Saltline》的中文镜像，原游戏的创作归属保持不变。

- 原作者：**Felix Rieseberg**；据作者介绍，游戏使用 **Claude Fable 5.2** 制作。
- [作者发布记录](https://x.com/felixrieseberg/status/2119925633564463609)
- [原始可玩 Artifact](https://claude.ai/artifact/BGY1SztrAYcJQHSsnHHGmp)
- [本地运行版本的上游镜像](https://github.com/realcodebear/saltline-fable-5.2)

作者发布记录提到：一次提示词、无人工反馈、约 8 小时，约 270 万输出 token 和 4.45 亿输入 token（大量缓存），按 API 标价约 550 美元。这些数字来自作者陈述，本仓库未独立核验。

上游镜像移除了 Claude 页面专用的 frame-runtime 脚本，并补充了 doctype、字符编码和 viewport 配置；本仓库在此基础上增加简体中文界面和第二章“回声协议”。新增章节不代表原作者的官方续作。若原作者希望撤下镜像，可在仓库中提交 issue。

整个游戏集中在约 **1.4MB** 的 `index.html` 中，内嵌 Three.js。模型、材质与音效由代码生成；页面字体会请求 Google Fonts，无法加载时使用本机字体。

## 验证

任务状态机测试使用 Node.js 自带测试运行器，无需安装依赖：

```sh
node --test tests/campaign.test.cjs
```

新增章节的可读源码位于 `index.html` 的 `saltline-campaign` 内联脚本中，原始渲染引擎继续内嵌，游戏仍可作为单个 HTML 文件运行。
